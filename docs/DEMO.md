# НарядAI — сценарий защиты (Demo Day 16.10.2026)

Сквозной сценарий из раздела 11 ТЗ, около 7 минут, на 2–3 телефонах.

## Подготовка (накануне и за 30 минут)

**Сервер**
- [ ] Администратор: «Справочники → Демонстрационная история → Загрузить историю» (570+ нарядов за 90 дней).
- [ ] Ключ LLM задан (`ANTHROPIC_API_KEY`), в отчёте видна кнопка «Сводка ИИ». Без ключа всё работает на правилах, и это честно подписано.
- [ ] Пороги («Справочники → Контроль сроков»): для демо поставить «напоминание до срока» 5 мин и «повтор просрочки» 5 мин.
- [ ] Cron работает: в логах Cloudflare раз в минуту `deadline check`.

**Телефоны**
- [ ] Телефон 1 — мастер (`master`), телефон 2 — слесарь Иван Петров (`worker1`), телефон 3 (по возможности) — электрик (`worker2`) или руководитель (`manager`).
- [ ] На каждом приложение установлено на главный экран («Установить на телефон»), уведомления включены («Уведомления → Включить», затем «Проверить push»).
- [ ] Звук телефона включён, режим «Не беспокоить» выключен.
- [ ] На смене (Сотрудники → «На смену») только реальные учётки: так ИИ подберёт исполнителя с телефона 2.

**Реквизит**
- [ ] Фото «течь масла на насосе» до и после (заготовка или реальный узел).
- [ ] Напечатанная QR-этикетка насоса Н-12 («Справочники → QR-этикетки»).
- [ ] Ноутбук с проектором: веб-панель мастера и отчёты.

## Запасной план

- **Нет сети в зале.** Включите видео из папки сдачи. Отдельно покажите офлайн-режим: действия исполнителя сохраняются на телефоне и уходят при появлении связи.
- **Push не пришёл.** Наряд всё равно появляется у исполнителя через ≤ 4 с со звуком и красным окном в открытом приложении.
- **ИИ-модель недоступна.** Отчёт сохраняется с проверкой по правилам и пометкой «Резервная проверка» — это и есть надёжность.
