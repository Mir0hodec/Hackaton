# HTTP в локальной Wi-Fi-сети

Для Windows используйте IPv4-ссылку из запасного QR с портом: сейчас `http://192.168.1.120:8788/demo`. На другом устройстве localhost и 127.0.0.1 обозначают само устройство. Имя .local требует mDNS.

## Фото и зависание отправки

Браузер по HTTP IPv4 не предоставляет crypto.randomUUID(). Это вызывало ошибку при добавлении фото и зависание отправки наряда. Клиент теперь использует lib/client-id.ts: нативный UUID, если доступен, или UUID v4 на основе crypto.getRandomValues(). Ошибка генерации ID обрабатывается внутри try/finally, чтобы разблокировать форму.

После обновления сервера обновите открытые страницы на телефоне и Windows. По HTTP IPv4 в браузере проверены прикрепление изображения, сохранение наряда, мобильный отчёт с фото, смена статусов, приёмка мастером и два ответа OpenRouter.

Документация: [randomUUID](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID), [getRandomValues](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues).

## Если Windows вообще не открывает страницу

Сервер Start-LAN должен оставаться запущенным на Mac. Используйте актуальный адрес из /lan: DHCP может менять IPv4. На Windows выполните, заменив адрес актуальным:

```powershell
Test-NetConnection 192.168.1.120 -Port 8788
curl.exe --noproxy "*" -v --max-time 10 http://192.168.1.120:8788/api/lan-discovery
```

TcpTestSucceeded: False означает отсутствие TCP-соединения. Проверьте обычную общую Wi-Fi-сеть, изоляцию гостевой сети и маршрутизацию VPN. Если TCP проходит и curl возвращает JSON, проверьте полный http:// адрес, прокси браузера и разрешение локальной сети. Команды ничего не меняют.

На Mac подтверждены слушатель *:8788, IPv4 192.168.1.120/24 и входящее TCP-соединение от другого адреса той же подсети. Системный firewall уже был выключен. Это подтверждает доступность для одного устройства, но не успешное подключение конкретного Windows-ноутбука. Физические Windows и телефон в этой проверке недоступны.

Камера, микрофон, service worker и браузерные push могут требовать HTTPS. Обычная форма и загрузка выбранного изображения работают по HTTP LAN.
