# Объединение NaryadAI с Hackaton

База: `Mir0hodec/Hackaton`, `main` на коммите `cd835f0`. Улучшения локальной версии NaryadAI перенесены в эту базу отдельными изменениями. Проверки выполнены 7 октября 2026 года.

## Что добавлено

- FIFO по времени постановки в очередь, включая переход «очередь → принят». Проверка очереди учитывает участников бригадного наряда; новый аварийный наряд допускает срочный старт.
- Атомарный старт в D1: один SQL UPDATE проверяет версию и занятость всех участников. Старт независимой карточки работы также проверяет текущий наряд. Таймер, связанный с этим же нарядом, совместим с его выполнением.
- Подбор свободного сотрудника нужной специальности перед сравнением опыта и рейтинга. Если кандидата нет, интерфейс предлагает ручной выбор с объяснением.
- Разбор отчёта по отдельным проверкам: описание, шифр, фото, материалы, время, сопоставление ключевых слов. Проверка правил не выдаётся за анализ изображения.
- Строгая валидация ответа модели; низкая уверенность и непереданные изображения требуют проверки мастером. Модель сохраняет формальные замечания и обязательную доработку.
- Расход с точностью до 0,001 в срезах по материалу, участку, оборудованию и исполнителю; разные единицы не суммируются. Бригадные наряды учитываются однократно.
- Отменённые и отклонённые заявки исключены из сигналов поломок. Сравнение частоты ограничено выбранным набором оборудования; при выборе одной единицы сравнения со средним нет. Выводы открывают реальные наряды-источники.
- Произвольный период считается по времени предприятия UTC+5. Сохранены восемь листов XLSX; в них добавлены срезы материалов, активное время и источники выводов.
- Быстрый наряд со сроком 2/15/60/120 минут, скрываемые дополнительные фильтры, доступ к остальным позициям расхода, исправление ширины шапки и таблиц на телефоне.
- Регрессионные тесты и GitHub Actions для типизации, сборки, правил, XLSX и локальных API-сценариев.

## Сохранённые функции базы

Голосовой ввод, QR, интерфейс исполнителя на казахском, фоновые модели Claude/OpenAI/mock, dHash/EXIF, PDF карточки наряда, ассистент с инструментами, импорт истории, параметры напоминаний, интеграционный API, роли и учётные записи, Cloudflare Cron, хранение фото в R2 или D1.

## Настройки и пределы проверки

Изображения передаются внешнему провайдеру только при `AI_PHOTOS_APPROVED=true`. Без разрешения, при ошибке чтения части фото и в режиме mock содержимое проверяет мастер; `photoScore=0`. В демо модель остаётся отключённой по прежним правилам.

Настоящие Claude/OpenAI, физический телефон, камера/микрофон и доставка push на устройство в этом объединении не проверялись. Mock подтверждает конвейер, а не точность модели. Мобильная проверка использует браузерные размеры экрана. Прогноз по частоте обозначен как некалиброванная экстраполяция, не вероятность аварии.

Миграция схемы для новых функций не требуется. Рабочая база и внешний деплой не изменялись; тестовые данные и настройки `.dev.vars` не входят в Git.
